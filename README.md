# SlimRoom

Статическая одностраничка на React, TypeScript и Vite. Русский, английский и греческий языки, адаптивная верстка и запись через WhatsApp. Backend, аккаунты и база данных не нужны.

## Локальный запуск

Node.js 22.12+ (рекомендуется 24).

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## GitHub Pages

1. Загрузите проект в GitHub-репозиторий, ветка `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует `dist` при push в `main`. Можно запустить вручную через вкладку Actions.

`base: './'` обеспечивает относительные пути к ресурсам: сайт работает как в корне домена, так и в `/имя-репозитория/`. Все переходы — якоря на этой странице, поэтому обновление страницы не требует серверного роутинга. Настройка соответствует [руководству Vite для статического размещения](https://vite.dev/guide/static-deploy.html#github-pages).

## Контент и структура

- `src/site/content.ts`: тексты RU/EN/EL, процедуры и контакты; единый источник для карточек, формы и WhatsApp.
- `src/site/App.tsx`: секции страницы и переключение языка. Выбранный язык сохраняется, если localStorage доступен.
- `src/site/BookingForm.tsx`: доступная форма с нативной проверкой обязательных полей.
- `src/site/booking.ts`: подготовка URL WhatsApp с кодированием текста.
- `src/site/styles.css`: адаптивные стили; системные шрифты используются при недоступности Google Fonts.
- `src/assets`: оригинальные фотографии пользователя; `src/assets/optimized`: уменьшенные копии для сайта.

Контент перенесён из `slimmalina/frontend`: `i18n.ts`, `components/TherapiesSection.tsx`, `pages/Contact.tsx`, `components/ContactSection.tsx`, `pages/About.tsx`. Список процедур обновлён по предоставленному Алиной перечню: классический и комплексный антицеллюлитный массаж, мадеротерапия с баночным массажем, терапевтический массаж, массаж для беременных, детский массаж, скульптурный и биоэнергетический скульптурный массаж лица, индивидуальная растяжка. Названия и описания адаптированы на RU/EN/EL. Все сеансы длятся 60 минут, детский массаж — 30 минут. Цены на сайте не отображаются. Динамический контент из базы исходного проекта не выгружался. Указана только страна, поскольку исходные страницы расходятся в указании города. Контакт WhatsApp: **+357 95 111 676**; Instagram: **@massage.slimroom**.

Кнопка формы открывает WhatsApp в текущей вкладке с именем, телефоном, выбранной процедурой и заполненными дополнительными полями. Клиент сам отправляет сообщение. Это запрос на запись: время подтверждается Алиной. Форма не сохраняет персональные данные в браузере или на сервере.

Блок «Квалификация и сертификаты» перенесён в RU/EN/EL из `slimmalina/backend/src/config/default-config.ts` (`aboutPage.content.credentialsList`). Число клиентов уже отображается в основной статистике. Фотографии сертификатов в исходном frontend отсутствуют: старый сайт получает их через `/api/admin-certificates` из базы и S3. Учебный PDF `certificate-example-en.pdf` относится к сертификатам учеников и не используется как сертификат Алины. Копирайт: `SlimRoom`, текущий год вычисляется через JavaScript.

## Проверка

```sh
npm run check
npm run build
npm test
```

Браузерные тесты используют установленный Google Chrome. Они проверяют production-сборку под `/alina-lending/`, загрузку фотографий, мобильную верстку, сохранение языка, выбор процедуры, валидацию и содержимое WhatsApp-сообщения. Реальные сообщения не отправляются.
